Arrays and constructors¶

For examples and storage behavior, see the sparse array guide. SparseArray is the public array class. Legacy aliases have been removed.

SparseArray¶

The constructor accepts a shape or existing data. A tuple is interpreted as a shape; use sppy.asarray to treat a tuple as values. The constructor defaults to row storage; order="C" or order="F" explicitly selects storage.

Properties include shape, ndim, size, dtype, order, nnz, and T. nnz counts stored entries; use count_nonzero for nonzero values. parallel_dot uses Eigen kernels; OpenMP builds can run supported kernels in parallel. Without OpenMP, the kernels run serially.

sppy.sparse_array.SparseArray(data, dtype=None, *, order='C') ¶

An owned Eigen sparse vector or matrix.

Parameters: data: A shape (integer or tuple), dense data, sparse array, or SciPy sparse object. dtype: Signed integer, float32/64, or complex64/128 dtype. Inferred from data. order: "C" for row-major or "F" for column-major storage. Defaults to "C".

Tuple input specifies a shape. Use :func:sppy.asarray to treat tuples as data. Sparse indexing returns independent copies, rather than views.
