Arrays and constructors¶

For examples and storage behavior, see the sparse array guide. SparseArray is the preferred name; csarray remains a compatibility alias.

Constructors¶

sppy.util ¶

NumPy-style constructors for Eigen sparse arrays.

asarray(a, dtype=None, order=None, *, copy=None) ¶

Convert to a sparse array, reusing compatible sparse input when possible.

Dense input is copied into Eigen storage. Supported dtypes are signed integers (8/16/32/64 bits) and float32/float64.

zeros(shape, dtype=float, storage_type=None, *, order='C', **kwargs) ¶

Create an empty sparse array; order selects row or column storage.

ones(shape, dtype=float, storage_type=None, *, order='C', **kwargs) ¶

Create an array of ones (every element is stored explicitly).

eye(n, m=None, k=0, dtype=float, order='C') ¶

Create a sparse identity, optionally rectangular or offset by k.

The old eye(n, dtype) positional spelling is also accepted.

diag(v, k=0, *, order='C', storagetype=None) ¶

Construct an offset diagonal, or extract one from a matrix.

rand(shape, density, dtype=float, storagetype='col', *, order=None, rng=None) ¶

Sample sparse values; pass a NumPy Generator for reproducible new code.

Coordinates are sampled with replacement, so actual density may be lower than the requested density. The legacy global NumPy RNG remains supported.

SparseArray¶

The constructor accepts a shape or existing data. A tuple is interpreted as a shape; use sppy.asarray to treat a tuple as values. The constructor defaults to column storage; order="C" or order="F" explicitly selects storage.

Properties include shape, ndim, size, dtype, order, nnz, and T. nnz counts stored entries; use count_nonzero for nonzero values. parallel_dot aliases pdot; OpenMP builds can run its kernels in parallel. Without OpenMP, the kernels run serially.
