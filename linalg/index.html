Linear algebra¶

Import functions from sppy.linalg. The solver uses floating-point sparse matrices; randomized SVD also accepts dense arrays and general linear operators.

Solve a linear system¶

import numpy as np
import sppy
from sppy.linalg import bicgstab, norm

a = sppy.asarray([[4., 1.], [1., 3.]])
b = np.array([1., 2.])
x, status = bicgstab(a, b, rtol=1e-10)
assert status == 0
np.testing.assert_allclose(a @ x, b)
frobenius = norm(a)

Always inspect status: 0 means success, 1 a numerical issue, 2 no convergence, and 3 invalid input. These are SpPy's codes and differ from SciPy's convention. norm computes only the Frobenius norm; its ord argument is currently ignored.

Randomized SVD¶

from sppy.linalg import rsvd

u, singular_values, v = rsvd(a, k=1, p=1, q=2)
approximation = (u * singular_values) @ v.T
assert approximation.shape == a.shape

rsvd returns right singular vectors as columns of v, rather than returning v.T. Increase p (oversampling) or q (power iterations) to improve the approximation. Sampling uses NumPy's global random state.

rsvd(A, k, p=10, q=2, omega=None) ¶

Compute the randomised SVD using the algorithm on page 9 of Halko et al., Finding Structure with randomness: stochastic algorithms for constructing approximate matrix decompositions, 2009.

Finds the partial SVD of a sparse or dense matrix A, resolving the largest k singular vectors/values, using exponent q and k+p projections. Returns the left and right singular vectors, and the singular values. The resulting matrix can be approximated using A ~ U s V.T. To improve the approximation quality for a fixed k, increase p or q.

General linear operators¶

Wrap a matrix with GeneralLinearOperator.as_linear_operator(a) to expose matvec, rmatvec, matmat, and rmatmat callbacks. Combine operators lazily with as_linear_operator_sum(left, right).

sppy.linalg.general_linear_operator.GeneralLinearOperator ¶

Bases: object

A more general form of LinearOperator in scipy.linalg. Can be used with many of the scipy functions.

The new operation is rmatmat which is X.T V.
